# המסלול שלנו

אפליקציית PWA בעברית למעקב אחרי צום לסירוגין (ADF) ומשקל, לשני אנשים.

- קוד סטטי (HTML/CSS/JS), בלי שלב build.
- **פרטיות:** אין בקוד שום נתון אישי. הכול נשמר רק ב־localStorage במכשיר.
  יש גיבוי (ייצוא JSON) ושחזור בהגדרות ⚙️.
- בדיקות דם, סוג צום והתאמות בריאותיות – לכל פרופיל, נשמרים רק במכשיר.
- מסמכים (PDF/תמונות, למשל תפריטים מעודכנים) נשמרים ב־IndexedDB במכשיר בלבד –
  לא עולים לשום שרת. אפשר לכלול אותם בגיבוי (base64).
- עובד אופליין (service worker), אפשר להוסיף למסך הבית.
- הגרף משתמש ב־Chart.js מ־CDN, שנשמר במטמון לשימוש אופליין.
